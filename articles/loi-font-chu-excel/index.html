Lỗi font chữ Excel bị vỡ? Cách sửa nhanh và triệt để

Trả lại khả năng đọc hiểu chữ tiếng Việt chuẩn cho mọi văn bản mà bạn nhận được.

Trang chủ > Lỗi Font Chữ

Tóm tắt nhanh: Lỗi font trong Excel thường xảy ra khi file dùng bảng mã cũ (VNI, TCVN3) hoặc máy bạn không có font tương ứng. Cách xử lý nhanh nhất là chuyển về Unicode hoặc cài đúng font thiếu.

Vì sao Excel bị lỗi font chữ?

Bạn mở file Excel ra và thấy toàn ký tự lạ như ô vuông, dấu hỏi hoặc chữ bị méo hoàn toàn? Đây là lỗi rất phổ biến khi làm việc với file từ máy khác.

Nguyên nhân chính không phải do Excel “lỗi”, mà là do sự không tương thích giữa bảng mã và font chữ.

Nguyên nhân phổ biến

  • Khác bảng mã: File dùng bảng mã cũ như VNI hoặc TCVN3 nhưng máy bạn đang dùng Unicode.
  • Thiếu font: Máy người gửi có font (ví dụ .VnTime), nhưng máy bạn không có nên Excel tự thay thế font → gây lỗi hiển thị.
  • Copy từ nguồn ngoài: Copy dữ liệu từ web hoặc phần mềm khác nhưng sai bảng mã.

Cách sửa lỗi font trong Excel

Cách 1: Chuyển về Unicode bằng Unikey (khuyên dùng)

Đây là cách nhanh và sạch nhất để xử lý triệt để lỗi font.

  1. Copy toàn bộ nội dung bị lỗi trong Excel (Ctrl + C).
  2. Mở Unikey Toolkit bằng tổ hợp Ctrl + Shift + F6.
  3. Chọn đúng bảng mã:
    • Source: VNI Windows hoặc TCVN3 (tùy dữ liệu)
    • Destination: Unicode
  4. Nhấn Chuyển mã.
  5. Quay lại Excel và dán (Ctrl + V).

Sau bước này, dữ liệu sẽ hiển thị bình thường với các font phổ biến như Arial hoặc Calibri.

Cách 2: Cài thêm font còn thiếu

Nếu file bắt buộc phải giữ nguyên định dạng (ví dụ tài liệu hành chính), bạn cần cài đúng font gốc.

  • Tải bộ font VNI / TCVN3 từ internet
  • Giải nén file
  • Chọn toàn bộ file .ttf → chuột phải → Install
  • Mở lại Excel

Cách 3: Kiểm tra lại khi copy dữ liệu

Khi copy từ web hoặc nguồn ngoài:

  • Đảm bảo Unikey đang để bảng mã Unicode
  • Tránh copy trực tiếp từ nguồn không rõ encoding

Kết luận

Lỗi font Excel không phải vấn đề nghiêm trọng. Chỉ cần xác định đúng nguyên nhân:

  • Sai bảng mã → chuyển Unicode
  • Thiếu font → cài thêm font

Là bạn có thể xử lý gần như 100% trường hợp mà không mất dữ liệu.
