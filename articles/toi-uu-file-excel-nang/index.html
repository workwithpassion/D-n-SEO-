Cách tối ưu file Excel bị nặng và chạy chậm

Tiết kiệm hàng giờ chạy vòng lặp Calculation với các bước giảm tải file excel nặng hiệu quả.

Trang chủ > Tối Ưu Hóa Excel

Tóm tắt nhanh: File Excel chậm do tệp dữ liệu phình to hoặc chạy vòng lặp các hàm mảng. Lọc dữ liệu, lưu giá trị tĩnh, và tối giản hoá là chìa khoá xoá bỏ hiện tượng giật lag.

Nguyên nhân khiến tệp phình to

  • Quá nhiều công thức mảng: Đặc biệt là VLOOKUP đối chiếu chéo sang Sheet ngoại bang tới chục nghìn dòng.
  • Dữ liệu rác: Định dạng màu nền tràn ngập ra ngoài vùng báo cáo hàng triệu ô trống (Blank cell color format).
  • Ảnh nhúng độ phân giải cao: Chèn thẳng ảnh PNG chưa giảm kích thước.

Cách tối ưu hóa cho dân văn phòng

1. Đóng băng dữ liệu tham chiếu cũ

Thay vì để 12 tháng dữ liệu chạy lệnh tính toán, hãy bôi đen từ tháng 1 đến tháng 11, Copy và ấn Paste Value để đóng băng nó thành số chết. Chỉ giữ lại tháng 12 chạy công thức.

2. Xóa dữ liệu vô hình thừa thãi

Chọn dòng cuối cùng có chứa dữ liệu thật sự, bôi đen kịch đến dòng đáy của Excel (dòng thứ 1 triệu), nhấn chuột phải Delete Entire Row. Làm tương tự với cột ngoài cùng lề phải. Nhấn Save để tận hưởng file thu hẹp dung lượng.

3. Nén tệp hình thể và tách file

Data nếu chạm mốc 500,000 nghìn dòng thì việc chia file nhỏ theo Quý hoặc Năm để thao tác sẽ nhẹ gánh cho RAM máy tính hơn. Excel lưu với khung .xlsb (Binary Format) thay vì .xlsx thông thường cũng giúp nén khối lượng nén dữ liệu cực nhẹ cho file thuần Text.

Có thể bạn quan tâm:

  • Sửa lỗi #NAME? do đánh máy sai tên hàm
  • Khắc phục lỗi #DIV/0! khi thực hiện chia
